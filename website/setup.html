Setup · about 5 minutes

Get your Gemini API key

LibreLookAI runs on your own Google Gemini API key. It is stored only on your phone and used directly with Google — there is no subscription to us.

What you want to do Key you need
Auto-tagging, outfit suggestions, packing lists, trend search Free key
Virtual try-on, background removal — anything that creates an image Billing-enabled (paid) key

✦ Why paid? Try-on and background removal use Gemini's image generation, which Google does not offer on the free tier. You still only pay Google for what you use — usually a few cents per image.

Three steps

1

Create the key (free)

In the app, tap Get an API key (or open aistudio.google.com). Sign in, tap Create API key, and copy it — it starts with AIza…

2

Paste it into LibreLookAI

Back in the app, paste the key into the API Key box. Tagging and outfit suggestions work right away. You can change it later under Settings ▸ Advanced ▸ Gemini API key.

3

Enable billing (for try-on)

To unlock virtual try-on and background removal, tap Enable billing (or open AI Studio billing), pick the same project, and add a payment method. New accounts usually include free credit.

Common questions

Is my key safe? Yes. It is saved only on your device and sent straight to Google's API — never uploaded to us or synced to your Drive.

How much does it cost? Tagging and suggestions on the free tier are free. Image features (try-on, background removal) are billed by Google per image — usually a few cents each, and you can set spending limits.

Try-on says it failed. That key probably doesn't have billing enabled yet. Do step 3 above, then try again.
