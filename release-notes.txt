### LibreLookAI v1.6.0 Release Notes

#### New
- Wardrobe redesign: header now shows Title · Closet · Filters pill · Find-by-Photo · Sort · Settings, with an active-filter count badge.
- Filters pill opens a bottom sheet with all tag categories (Reset / Apply).
- Quick-category chip row under the header — All / Tops / Bottoms / Outerwear / Footwear / Accessories / Dresses / Suits, each with live counts; tap to single-filter.
- Theme picker in Settings → Display: 7 palettes (Green light/dark, Sand light, Indigo dark, Pastel Mint/Blush/Lavender) applied app-wide.

#### Improvements
- Rotation-invariant pHash channel added to similarity scoring for steadier matches when items are photographed at different angles.
- Old "X of Y items" count line removed from the wardrobe header — counts now live on the category chips.
