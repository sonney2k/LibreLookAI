### LibreLookAI v1.7.1 Release Notes

#### Outfits
- Find-with-AI now opens a setup sheet first (goal text, weather, closet, vibe chips) so you can steer the suggestion before Gemini runs. Your input is threaded into the prompt and survives refinement rounds.

#### UI polish
- Fullscreen viewers (Wardrobe, Outfit item, Shopping, Try-On) drop the redundant top/bottom panels — the image fills more of the screen.
- Wardrobe item viewer no longer leaves blank space at the top; the navigation row overlays the image.
- Dangerous actions (delete buttons, destructive confirmations) now use a single solid-red style across every screen.

#### Translations
- Composer bottom sheets (weather, closet, vibes) now follow the in-app language inside their own windows instead of falling back to the device locale.
